# Titanic Passenger Survival Analysis

## Project Overview
This project explores passenger survival patterns on the Titanic using Python. The analysis focuses on data cleaning, exploratory data analysis (EDA), and visualizing the relationship between passenger characteristics and survival.

## Objectives
- Inspect and understand the dataset.
- Identify and handle missing values.
- Calculate passenger survival rates.
- Compare survival rates across passenger classes, genders, and age groups.
- Visualize patterns using charts.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Jupyter Notebook / Google Colab

## Project Workflow
1. Loaded and inspected the dataset.
2. Examined dataset dimensions, column names, data types, descriptive statistics, and missing values.
3. Filled missing Age values using the median.
4. Removed the Cabin column and filled missing Embarked values using the mode.
5. Performed exploratory analysis of age, fare, and survival.
6. Compared survival rates by passenger class, gender, age group, and gender combined with passenger class.
7. Created visualizations to communicate the findings.

## Key Analysis Areas
- Survival rate by passenger class
- Survival rate by gender
- Age and survival patterns
- Survival rates across age groups
- Survival rates by gender and passenger class

## How to Run
1. Clone or download this repository.
2. Install the required libraries:
   `pip install pandas matplotlib jupyter`
3. Ensure `train.csv` is in the same directory as the notebook.
4. Open `Titanic_Data_Analysis.ipynb` in Jupyter Notebook or upload it to Google Colab.
5. Run the notebook cells in order.
